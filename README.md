# DSH 全局默认策略（Global Default Policy for DSH Agent）

> 本仓库保存 **DSH 智能体的用户全局基线**：安全性、数据安全、个人数据保护的默认要求。
> 每次会话自动加载，创建模式 / 项目 / 技能 / 工作流时默认执行，无需用户重复提醒。

## 这是什么

一份最高优先级的全局指令文档（`AGENTS.md`），被 DSH 的 `dsh-agent-instructions`
插件在**每次会话开始时自动加载**，作为所有会话的默认底线：

- **安全性**：最小权限、密钥不落盘、输入校验与注入防护、信任边界、依赖安全
- **数据安全**：分级加密、最小收集、防泄露、留存与销毁
- **个人数据保护**：目的限定、最小化、知情同意、匿名化 / 聚合脱敏
- **适配范围**：仅适配 DSH 智能体（本会话）；用户明确要求时才做多 agent 适配

## 安装 / 使用

1. 把本仓库的 `AGENTS.md` 复制到你的 DSH 主目录：

   ```powershell
   Copy-Item AGENTS.md "$HOME\.dsh\AGENTS.md"   # Windows
   # 或
   cp AGENTS.md ~/.dsh/AGENTS.md                # macOS / Linux
   ```

2. 之后**每个新会话都会自动加载**这份策略，无需手动开启。
   （`$DSH_HOME` 可通过环境变量覆盖，默认 `~/.dsh`。）

## 修改

直接编辑 `AGENTS.md` 即可；文件变更会在后续会话自动生效。

## 例外

用户具体任务中的明确要求优先于本默认策略；系统 / 开发者指令始终优先。
